3xtools QR Suite - Documentation

Complete guide to running, configuring, and rebranding the premium offline QR designer template.

Overview

The 3xtools QR Suite is a premium, realtime, vector QR Code generator and styling engine built on React 19, Vite, and Tailwind CSS v4. Designed for ultimate privacy and visual excellence, the application performs all calculations, pattern overrides, frame drawings, and bulk ZIP compressions completely client-side.

It requires no backend database, no third-party APIs, and no server maintenance. This makes it incredibly easy to rebrand, configure, and upload to any hosting provider.

💡

Zero server maintenance: Since the suite runs strictly in the buyer's browser, you can host it for free on Vercel, Netlify, Cloudflare Pages, or drag-and-drop the pre-built files onto shared cPanel hosting!

Key Features

The application is packed with high-value developer and consumer features that guarantee high user retention:

Data Modes
Interactive inputs for links, plain text, email, phone, SMS, WhatsApp pre-fills, Wi-Fi details, vCards, Geo locations, and iCalendar events.
Advanced Styles
Customize data pixel patterns (dots, rounded, diamonds, liquid, lines) and corner locator eye borders and pupil dots dynamically.
Premium Frames
Banners, top/bottom ribbons, phone mockups, border tags, and film clapperboards with customizable typography, sizing, and colors.
Bulk Generation
Drag and drop CSV files or write lists. Renders paginated previews dynamically and downloads all codes bundled inside a zip file client-side!

Local Development Setup

Follow these steps to run the application in a local development environment:

1

Extract Code Package

Unzip the downloaded CodeCanyon package and locate the Source Code/ folder which contains the React + Vite repository.

2

Install Node.js Dependencies

Open your terminal/command prompt in the project root directory and run the following command to download dependencies:

Terminal / Command Line 
npm install
3

Start Local Development Server

Spin up Vite's HMR local development server by executing:

Terminal / Command Line 
npm run dev

Open your browser and navigate to the address shown in terminal (typically http://localhost:5173).

Build & Deploy for Production

To compile the optimized, compressed static code ready to run on any online hosting environment, run:

Terminal / Command Line 
npm run build

Vite will build and output an optimized production bundle inside the dist/ folder. This folder contains a single index.html alongside compiled, obfuscated assets/ (js, css) and static media files.

⚠️

cPanel Shared Hosting note: Simply drag the files inside the built dist/ folder (not the folder itself) and drop them inside your domain's root folder (usually public_html/) using cPanel File Manager or FTP, and your site is live immediately!

Troubleshooting & FAQs

Q: What should I do if the built page displays a blank screen?
A: Open your browser's console (F12) to inspect errors. Most blank screens on cPanel are caused by server directory routing issues. If you host inside a subdirectory (e.g. example.com/qr/), open vite.config.js and configure the base parameter: base: './' or base: '/qr/', and compile again.

Q: The Bulk ZIP download does not run?
A: The bulk ZIP compilation uses JSZip completely client-side in the browser's RAM memory. If buyers upload extremely large CSV files (e.g. 10,000 rows), the browser might hit heap memory limits. Advise buyers to split files into smaller batches of 1,000 rows to ensure fast Zip compression.

Q: Can I integrate ads (like Google AdSense) on this template?
A: Yes, easily! You can add Google AdSense scripts inside the index.html file or add styled banner components inside `Navbar` or `Footer` containers.
